# Command Examples

## Create a problem dossier

```bash
make new-problem TITLE="Exact claim or gap" TRACK="main"
```

## Validate structured state

```bash
make validate
make eval
```

## Natural-language research requests

- “Normalize this claim, list hidden hypotheses, and create a dossier.”
- “Use `LIGHT` to prove or refute this bounded lemma.”
- “Use `FULL` to compare genuinely different mechanism families.”
- “Attack this candidate independently and state the exact surviving gap.”
- “Find the exact primary-source theorem and check that its hypotheses match.”
- “Give me the high-level project map and the next three discriminating steps.”
- “Приведи лабораторию в порядок как следует: исправь безопасные дефекты,
  перепроверь статусы и закончи свежим обзором.”
