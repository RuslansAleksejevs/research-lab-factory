# Literature Sweep

Freeze the query and terminology variants. Prefer primary papers and books.
Record date, search surface, exact statement, theorem number, page, hypotheses,
and relationship to the target. Separate exact matches, related methods,
terminology leads, inaccessible items, and negative search evidence. Never infer
novelty from an incomplete search.

When the sweep is a substantive research round, preserve its bounded outcome
with `record-research-checkpoint`, linking the detailed source artifacts rather
than duplicating them. In read-only mode, return the schema-valid proposed
checkpoint input as `NOT_PERSISTED` for an authorized coordinator.
