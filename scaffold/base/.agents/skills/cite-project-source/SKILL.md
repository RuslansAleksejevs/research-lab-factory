# Cite Project Source

Inspect the actual source. Record exact filename and location, printed/PDF page
differences, statement, hypotheses, notation, and scope. Separate the source's
words from project interpretation. Mark an inaccessible or merely related
statement as unverified; never cite a search result, abstract, or model output
as authority.
