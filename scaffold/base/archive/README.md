# Archive

Archive superseded but historically useful artifacts without rewriting their
original mathematical status.

Do not create a separate archive chronology for ordinary research rounds.
Canonical dated outcome history lives in append-only
`research/checkpoints/`, while closed dossiers and status-partitioned results
remain in their existing locations. If a historically useful artifact is
placed here, link it from a checkpoint or dossier. Whole-laboratory surveys
include this tree except for `archive/migrations/**`.
