# Start here

Read [the current state](knowledge/resume.md), [the profile](LAB_PROFILE.json)
and [the initial method](methods/simple-v1.json). Work in the user's language.

A useful first request is: “Recover the current question and previous work.
Check which session records can actually be captured and which project
constraints apply. Run one bounded round: develop an argument, obtain criticism
from a separate context, and preserve the outcome, limits and next step.”

The agent follows [the round protocol](workflows/ROUND.md); the user does not
need to operate the archive manually. Unsupported capture remains an explicit
gap. A competition's authorship or submission rules apply only when that
competition is part of this project's actual profile.

Imported materials are listed in [the bootstrap report](BOOTSTRAP_REPORT.md).
Method and idea catalogs are options, not mandatory instructions. Recover prior
results and rejected approaches before spending another round on the same issue.

Refresh navigation with `python3 scripts/philosophy_round.py refresh`, then read
`research/views/index.md` or `research/views/timeline.md`. Run local checks with
`make doctor validate eval`. See [archive format](docs/ARCHIVE_FORMAT.md) and
[capture coverage](docs/CAPTURE.md) for the evidence boundaries. API purchases,
Git, publication and submission are separate explicit actions.
