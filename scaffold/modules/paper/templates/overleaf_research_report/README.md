# Overleaf Research Report Template

Copy this folder into a dated subfolder of `research_reports/` for a major research output.

Expected files:

- `main.tex`: main report.
- `macros.tex`: notation and macros.
- `status_table.tex`: claim-status table.
- `source_crosswalk.tex`: source-to-proof map.
- `references.bib`: bibliography.

The report should compile as a standalone Overleaf project.
