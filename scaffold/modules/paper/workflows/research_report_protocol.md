# Research Report Protocol

Major mathematical work should have a human-facing report and separate audit
artifacts. Markdown state files are backstage evidence unless the user asks to
inspect them.

## Required report structure

1. visible truth-status warning;
2. executive summary;
3. exact typed statement;
4. proof, refutation, computation, or exact residual gap;
5. conceptual explanation;
6. examples and boundary cases;
7. exact source crosswalk;
8. independent verification status;
9. next discriminating actions.

Prefer an Overleaf-ready LaTeX project and PDF when layout tools are available.
Never let typesetting quality promote mathematical status. Record actionable
format feedback in the laboratory's user preferences or improvement proposal
only after it is stable or explicitly requested.
