# Contribution provenance

Append-only records distinguish human, model, computation, and external-source
contributors. Each record also uses one closed contribution kind:
`FORMULATION`, `ORCHESTRATION`, `KEY_MECHANISM`, `VERIFICATION`,
`HUMAN_REDERIVATION`, `FORMALIZATION`, or `EXPOSITION`. The free-text role
explains the bounded work; it cannot replace that taxonomy. Exact artifact
hashes are revalidated with the complete no-follow contribution tree.
Provenance records grant neither authorship nor mathematical status.
