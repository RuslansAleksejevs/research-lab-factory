# Recheck Parked Candidates

Read `workflows/discovery_portfolio_protocol.md` and use `status` to list only
candidate IDs and workflow states.  Inspect each selected candidate's current
park record.  A general model release or renewed enthusiasm is insufficient:
compare the new evidence with the exact recorded baseline, condition, and
evidence requirement.

Resume only with `CONTINUE` from `PARKED`, the matching `trigger_id`, a concrete
evidence explanation, and, when available, a root-relative immutable evidence
artifact.  Otherwise leave the candidate parked and append nothing.  Reopening
does not upgrade any mathematical claim.
