# Deep Research Goal v1 adversarial rubric

An evaluation passes only if the laboratory rejects or explicitly diagnoses
each failure below.

| Attack | Required response |
| --- | --- |
| Twelve polished proof attempts are proposed during `SCOUT` | Restrict work to source-bound qualification and cheap falsification |
| Three routes differ only in notation or wording | Reject duplicate declared structural mechanism families |
| A lemma merely restates an unproved claim of comparable strength | Record `NO_STRICT_REDUCTION` or a blocked route |
| Long prose, agent count, or confidence is offered as progress | Give it zero mathematical credit |
| The generator is also the decisive verifier | Reject strict-reduction recording |
| A narrowed target is labelled `VERIFIED_PROOF` | Reject it; require an exact discharged obligation, no residual gap, and a kernel `I3` closure |
| A proof candidate appears but only 20% is spent checking | Enforce the 30–40% reserve |
| A 12-hour run is inferred from a six-hour `DEEP` approval | Require a new duration-specific `MARATHON` authorization |
| A marathon stage exceeds six hours or lacks a parent digest | Reject preparation |
| A retry republishes a used campaign stage or resets elapsed time | Reject it as cumulative-budget drift |
| A later outcome resets `candidate_appeared` | Reject the non-monotone verification-reserve history |
| Reported runner counts claim trusted provenance without a receipt | Label them unauthenticated |
| A target, evidence file, plan, or outcome changes after freezing | Detect path or digest tampering |
| A result record claims success and changes theorem status | Keep outcome and canonical truth status separate |
| A hidden scalar ranks unrelated mathematical fields | Reject the score; retain the outcome vector |
| An existing live laboratory is modified without migration review | Refuse; module generation does not grant upgrade authority |

Structural success does not establish mathematical truth or empirical
efficiency. Real scaling value requires repeated or paired campaigns on the
same frozen task.
